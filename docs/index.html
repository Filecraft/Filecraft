04 / THE BEST UPLOAD IS NO UPLOAD

On your computer.
End of story.

No account. No analytics SDK. No document server. No AI API. Apple’s on-device frameworks on Mac; your existing browser’s local codecs in Portable. Neither sends your documents to a server.

Small by construction.
No Electron. No bundled browser. No third-party runtime bundled. Portable needs an existing desktop browser. Release-size budgets are enforced in the build, not left as a marketing promise.

Private, with clear boundaries.
Source EXIF and GPS dictionaries are not copied. Visible private content remains visible. Synced folders still sync. Prepare is not sandboxed or a redaction tool. Full boundaries ↗

Preview notes, limitations & SHA-256 ↗
Extract. Open. Disconnect.

Extract the entire ZIP, then open Prepare-Portable/index.html in a current Chrome, Edge or Firefox desktop browser. Keep the files together. No installation, server or internet connection is needed after download. The browser is a separate prerequisite, not included in the download size.

Small package. Useful controls.

JPEG/PNG to PDF, byte limits, compression presets, grayscale, DPI ceilings, A4/Letter layouts and centered margins. Sort, reorder, rotate or split a spread into left/right pages. Up to 20 pages, 20 MB and 24 megapixels per image; 100 MB selected input.

What has actually been tested?

Chromium and Firefox offline file workflows passed on Windows Server 2022 and Ubuntu 24.04 CI, plus local macOS. Independent PDF rendering checks cover split order, grayscale pixels and paper geometry. Read the CI results ↗

Why is it a preview?

This is a separate early companion, not feature parity with the stable Mac app. No HEIC, PDF input, OCR or mobile-browser support. Preview displays embedded JPEGs at page geometry, not a full PDF renderer. Inspect the saved PDF in a reader. The browser controls download location and overwrite prompts; choose a new filename. Extensions, sync folders and OS memory handling remain outside Prepare’s control.

Release notes & SHA-256 checksum ↗
Install with your eyes open.

Expand the ZIP and drag Prepare.app to Applications. This release is ad-hoc signed, not notarized by Apple. If macOS blocks it, inspect the source and checksum before choosing whether to approve it in System Settings → Privacy & Security. Do not disable Gatekeeper globally. Managed Macs may not permit it.

What can it prepare?

1–20 single-frame JPEG, PNG or HEIC images, up to 40 MB and 80 megapixels each. No PDF inputs, OCR or searchable text layer. Check small text carefully after compression.

Public code. Ethical-source license.

Contributions are welcome. Prepare uses the Hippocratic License 3.0 core, with restrictions on harmful uses. It is not an OSI-approved open-source license. Read the license.

Build it yourself. Without a package hunt.

Prepare has no third-party Swift dependencies. You need Apple’s Swift toolchain, which is a separate, much larger download if not already installed. Build instructions ↗
