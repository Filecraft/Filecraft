# Filecraft

Prepara la copia adecuada. Comprueba qué ha cambiado.

Filecraft prepara documentos localmente en Windows, macOS, Linux y el navegador. Define tus requisitos, crea una copia independiente y conserva un recibo vinculado a su hash SHA-256.

[Descargar](https://filecraft.github.io/download/) · [Probar en el navegador](https://filecraft.github.io/workspace/) · [English: referencia completa](https://github.com/Filecraft/Filecraft/blob/main/README.md)

Sin cuentas ni subida de documentos. La conversión de Office prioriza el texto y no garantiza conservar el diseño. Los recibos no demuestran autenticidad ni seguridad. OCR y conversión multimedia requieren herramientas locales opcionales. Las extensiones no están publicadas en las tiendas. El desarrollo de aplicaciones móviles se ha retirado.

Código original bajo Apache-2.0. Desarrollo asistido por IA: [declaración](https://github.com/Filecraft/Filecraft/blob/main/docs/AI-DISCLOSURE.md). Traducción asistida por IA, sin revisión de un traductor profesional. La documentación inglesa es la referencia.
