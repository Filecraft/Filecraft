# Filecraft

Préparer une copie adaptée. Vérifier ce qui a changé.

Filecraft prépare des documents localement sous Windows, macOS, Linux et dans le navigateur. Définissez vos contraintes, créez une copie séparée et conservez un reçu lié à son empreinte SHA-256.

[Télécharger](https://filecraft.github.io/download/) · [Essayer dans le navigateur](https://filecraft.github.io/workspace/) · [English — référence complète](../../README.md)

Aucun compte ni téléversement de document. La conversion Office privilégie le texte et ne garantit pas la mise en page. Les reçus ne prouvent ni l’authenticité ni la sécurité. OCR et conversion multimédia nécessitent des outils locaux optionnels. Les extensions ne sont pas publiées dans les boutiques. Les applications mobiles ne sont plus développées.
