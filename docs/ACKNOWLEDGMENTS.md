# Acknowledgments and project conventions

Prepare uses Apple system frameworks and no third-party application packages.
Its page/check artwork and website are original project assets.

Repository conventions were informed by inspecting established projects:

- [LocalSend contributing guide](https://github.com/localsend/localsend/blob/6279d3e30d1d1290caee3b81549f8128a8b01d9f/CONTRIBUTING.md):
  practical local build instructions, tests, private security reporting and
  contributor responsibility. Prepare has its own AI-assistance policy.
- [HandBrake contributing guide](https://github.com/HandBrake/HandBrake/blob/9991ce06aaa275c928509f82ec4e7aac0482279d/CONTRIBUTING.md):
  focused contribution routing and explicit project scope.
- [ShareX repository](https://github.com/ShareX/ShareX): separate security policy,
  workflow automation and clear release-oriented project organization.

These are organizational inspirations, not code dependencies or endorsements.
No source code or documentation text was copied from them.
