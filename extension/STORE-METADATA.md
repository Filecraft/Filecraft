## Description

Keep document preparation beside the application you are completing. Open a
full local workspace from the toolbar, explicitly choose ordinary PDFs, reorder,
extract, duplicate or rotate pages, then check the copy against personal size,
page, dimension or filename rules. Save the copy and an optional JSON receipt.
Later, compare a saved copy's SHA-256 and byte count with its receipt.

Filecraft does not read websites, forms, browser history or downloads automatically.
It does not upload your documents, include analytics or fetch conversion code.
All transformation code ships in the package. No host or optional permissions
are requested. The toolbar opens an extension-owned tab using tabs.create;
no tabs permission is needed to open that tab.

This beta accepts ordinary unencrypted PDFs without forms, signatures or
annotations. It is not an OCR engine, compressor, visual PDF previewer, sanitizer,
portal integration or acceptance certification. Unknown checks remain unknown.
Review the saved copy in a PDF reader. Receipts are unsigned, editable JSON and
prove byte identity only relative to the chosen receipt. Save to local storage
if you do not want your operating system to sync files.

## Privacy questionnaire answers

- Personal/user document data collected or transmitted by extension: none.
- Third-party analytics/advertising/data sale: none.
- Remote executable code: none.
- Content scripts or host access: none.
- Account required: no.
- Processing: in the extension tab and local dedicated worker.
- Persistent document storage: only explicit browser file downloads; no extension
  database. Browser UI and file sync behavior remain under user/browser control.
