# Support

I maintain Prepare independently. Please use public issues for reproducible bugs
and discussions for questions: https://github.com/gonisulaimann/Prepare/issues

Before reporting, read the platform limitations and try a synthetic JPEG/PNG.
Share OS/browser/build version, steps, expected result, actual result and whether
it also occurs with a synthetic fixture. Redact paths and personal information.
Do not attach private documents, identity records or credentials. There is no
paid support contract or response-time commitment.

For security vulnerabilities, use private reporting rather than a public issue:
https://github.com/gonisulaimann/Prepare/security/advisories/new

Prepare is Hippocratic 3.0 core ethical-source software, not OSI-approved open
source. Project-owned future code follows the same license unless explicitly
stated otherwise. Build/test tools have their own licenses.
