# Community code of conduct

Prepare welcomes people of every background and experience level. Be patient,
precise and kind. Critique ideas and code, not people. Respect boundaries,
privacy and differing experience. Give credit and accept correction.

Harassment, threats, discriminatory language, sexualized attention, doxxing,
impersonation, spam and publishing someone else's private information are
not acceptable. These rules apply to project issues, pull requests,
discussions and other spaces where you represent this project.

## Reporting and enforcement

Contact the maintainer privately through
[Goni Sulaiman's GitHub profile](https://github.com/gonisulaimann) using any
contact route they make available. Do not include sensitive details in a
public issue. If no private route is available, use GitHub's **Report abuse**
mechanism on the offending content. For software vulnerabilities, use the
separate process in [SECURITY.md](SECURITY.md).

The maintainer may remove content, request a correction, issue a warning,
restrict participation or ban an account, proportionate to the conduct.
Threats and serious privacy violations can result in immediate removal.
Reports are handled as confidentially as practical, but confidentiality
cannot be guaranteed for content already made public. Appeals can be sent
through the same private route; GitHub platform decisions follow GitHub's
own appeal process.

This is Prepare's own concise policy, not a claim of adoption of another
project's full code of conduct.
