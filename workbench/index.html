    Local processing. Explicit boundaries.

    No account, uploads, analytics, fonts, storage or automatic updates. Extract the whole folder and open index.html in current desktop Chrome, Edge or Firefox. No server or internet is required. Your browser and extensions have their own privacy behavior.

    Text and vector pages are copied, not rasterized. No OCR, compression guarantee, PDF repair, password removal, form flattening, signature preservation or PDF/A certification. Interactive/protected files are rejected rather than silently changed. Document-level outlines and metadata are not promised to survive. Visible private information and embedded page resources are not sanitized.

    Parsing runs in a disposable worker with a 30-second deadline and cancellation. File/page limits reduce resource use but cannot bound every malicious compressed stream. Only open documents from sources you trust; browser memory can still be exhausted. Closing this tab discards the workspace. Import and Clear reset undo history.
